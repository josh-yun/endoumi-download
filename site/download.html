엔도우미 다운로드

병원 환경에 맞는
설치 파일을 선택하세요.

Windows와 macOS에서 엔도우미를 사용할 수 있습니다. 처음 설치한다면 아래 안내를 먼저 확인해 주세요.

최신 설치 파일

WinWindows용Windows 10 · 11 / 64비트↓ MacmacOS용macOS 데스크톱↓

최신 버전을 확인하고 있습니다.

현재 설치 파일은 시연과 사전 검증을 위한 배포본입니다. 실제 진료에 적용하기 전 병원 내부 검증이 필요합니다.

처음 시작하기

설치부터 병원 연결까지
세 단계면 충분합니다.

  1. 01

    설치 파일 실행

    사용 중인 운영체제에 맞는 파일을 내려받아 설치합니다.

  2. 02

    첫 컴퓨터 설정

    병원에서 메인으로 사용할 컴퓨터를 정하고 서버 시작을 선택합니다.

  3. 03

    다른 컴퓨터 연결

    같은 네트워크의 컴퓨터에서 연결 코드를 입력하고 사용할 역할을 선택합니다.

설치 중 안내가 필요할 때

운영체제별 안내

코드 서명 전 배포본에서는 운영체제의 보안 안내가 표시될 수 있습니다.

macOS앱을 열 수 없다는 안내가 표시될 때
  1. DMG에서 Endoumi를 응용 프로그램 폴더로 옮긴 뒤 DMG 창을 닫습니다.
  2. Finder → 응용 프로그램 → Endoumi를 열고, 경고가 표시되면 완료를 누릅니다.
  3. 시스템 설정 → 개인정보 보호 및 보안의 보안 영역에서 그래도 열기를 선택합니다.
  4. 확인 창에서 앱 이름을 확인한 뒤 열기를 누릅니다.

설정에 엔도우미가 보이지 않으면 응용 프로그램 폴더에서 앱을 다시 열어 경고를 띄운 직후 확인하세요. Apple 공식 안내

Windows“Windows의 PC 보호”가 표시될 때
  1. 경고 창에서 추가 정보를 선택합니다.
  2. 파일 이름이 엔도우미 설치 파일인지 확인한 뒤 실행을 누릅니다.
  3. 실행 버튼이 없다면 병원 보안 정책에서 차단한 상태일 수 있으므로 전산 담당자에게 설치 허용을 요청합니다.

설치를 위해 Windows 보안 기능 전체를 끄지는 마세요. Microsoft 공식 안내
