macOS 테스트 실행 안내

응용 프로그램 폴더의 엔도우미를 먼저 열어야 합니다.

  1. DMG에서 Endoumi를 Applications로 끌어 놓은 뒤 DMG 창을 닫습니다.
  2. Finder → 응용 프로그램 → Endoumi를 두 번 클릭하고, 경고가 나타나면 완료를 누릅니다.
  3. 바로 시스템 설정 → 개인정보 보호 및 보안으로 이동해 화면 맨 아래의 보안 영역까지 내립니다.
  4. “Endoumi 사용이 차단되었습니다” 옆의 그래도 열기를 누르고 다시 열기를 선택합니다.

엔도우미가 표시되지 않으면 Finder의 응용 프로그램 폴더에서 Endoumi를 다시 한 번 열어 차단 경고를 만든 직후 설정 화면을 확인하세요. 현재 macOS 파일은 Apple 공증 전 테스트 버전입니다. 이 페이지에서 직접 받은 파일에만 위 절차를 사용하세요. Apple 공식 안내

Windows 테스트 실행 안내

“Windows의 PC 보호”가 표시될 때

  1. 경고 창에서 추가 정보를 누릅니다.
  2. 앱 이름이 엔도우미 설치 파일인지 확인한 뒤 실행을 누릅니다.
  3. 실행이 표시되지 않으면 Smart App Control 또는 병원 보안 정책이 차단한 상태이므로 전산 관리자에게 설치 허용을 요청합니다.

현재 Windows 파일도 코드 서명 전 테스트 버전입니다. Windows 보안 기능 전체를 끄지 마세요. Microsoft 공식 안내
